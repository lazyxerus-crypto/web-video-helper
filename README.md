# 웹 영상 도우미 (Chrome Extension) v6.1.1 (이어보기 + Ohli24 실험 브랜치)

Chrome Manifest V3 확장 프로그램으로, 웹페이지 내 영상 전체화면, 5초 뒤로, 85초 건너뛰기, 이전/다음 화, 배속 슬라이더를 지원합니다.

> 일부 플레이어 및 사이트에서는 iframe 접근/자동재생 정책으로 기능이 제한될 수 있습니다. 사이트 접근 권한 `<all_urls>`를 사용하며, 웹스토어 배포 전에는 필요한 범위로 권한 최소화를 검토하세요.

웹 영상 도우미 v6.1.1 (이어보기 + Ohli24 실험 브랜치) — 확장 프로그램 아이콘 실행 / 자동 다음 화 · 자동재생 / 배속 슬라이더

## 설치

1. 5.0 등 이전 버전 확장 프로그램을 Chrome 확장 관리(chrome://extensions)에서 제거하거나 비활성화합니다.
2. ZIP 파일을 압축 해제하고 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다.
3. 영상 사이트를 새로고침하고, Chrome 도구 모음의 이 확장 프로그램 아이콘을 클릭합니다. 별도의 실행 단축키는 없습니다.

화면에서 표시되는 컨트롤은 여섯 개입니다:
⏪ -5초 | ⏩ 85초 | ⏮ 이전 화 | ⏭ 다음 화 | 배속(1.00~2.00×, 0.05 간격) | 닫기

- 닫기: 웹 전체화면을 끝내고 컨트롤을 감춥니다. 다시 사용하려면 Chrome 확장 아이콘을 클릭합니다.
- 자동 다음 화 및 자동재생은 활성화 상태에서 기본·고정으로 작동합니다(별도 토글 없음). 자동재생은 **소리 있는 재생을 먼저 시도**하고, Chrome이 이를 차단하면 음소거로 자동재생합니다. 이 경우 컨트롤 바에 안내가 표시됩니다.
- `ani.ohli24.com`은 `/e/<작품명> N화` 형식을 회차 규칙으로 인식합니다. 예를 들어 `디 플래그! 2화`의 다음 화는 `디 플래그! 3화`로 연결하고, `담배 고양이 11화`의 다음 화가 `12화(完)`이면 실제 페이지에 존재하는 `12화(完)` 링크를 사용합니다.
- Ohli24에서는 숫자만 더해 임의 URL을 만드는 대신 현재 페이지의 같은 작품 회차 링크를 검색해 이전/다음 화를 결정합니다. 마지막 화는 `(完)` 표시를 인식합니다.

- 사이트에 실제로 등록된 이전/다음 회차 링크를 이용하므로 slug=03 → slug=04a처럼 불규칙한 회차도 지원합니다.
- 마지막 화처럼 다음 화 링크가 없으면 임의 주소로 이동하지 않습니다.
- 영상 배속과 **영상별 마지막 시청 위치**가 `chrome.storage.local`에 저장됩니다. 새 탭과 다른 사이트에서는 영상 도우미가 자동으로 켜지지 않습니다.
- 영상을 보는 동안 약 5초 간격으로 시청 시간을 저장하고, 일시정지·탐색·페이지 이탈 시에도 저장을 시도합니다.
- 같은 회차를 다시 열고 확장 프로그램 아이콘을 누르면 영상 준비 후 저장된 시점으로 이동하고 기존 배속을 적용한 다음 자동재생합니다. Chrome의 자동재생 정책으로 소리 있는 자동재생이 차단되면 무음 자동재생으로 fallback하고 안내를 표시합니다.
- 저장 기준은 제3자 플레이어 iframe URL이 아니라 **주소창의 영상 회차 URL**입니다. 작품·회차·서버가 다른 URL은 별도로 기억합니다. URL이 바뀌면 기존 저장 위치와 연결되지 않을 수 있습니다.
- 영상이 정상 종료되면 해당 회차의 미완료 이어보기 기록을 삭제합니다. 오래된 기록은 120일 후, 전체 기록이 250개를 넘는 경우 오래된 순서로 정리합니다.
- 저장은 **이 브라우저의 로컬 확장 프로그램 저장소**에서만 이루어지며 다른 PC 또는 Chrome 프로필로 자동 동기화되지 않습니다. 확장 프로그램 삭제 또는 저장 데이터 초기화 시 시청 기록도 사라질 수 있습니다.
- 이어보기는 HTML5 `<video>`에서 동작하며 사이트의 외부 플레이어·DRM·스트리밍 형태에 따라 정확한 시점 복원이 제한될 수 있습니다.
- 현재 탭에서 영상 도우미를 켜면 같은 사이트의 다음 화/이전 화 이동과 새로고침 중 활성화 상태가 유지됩니다.
- 영상 플레이어 인식은 기존 방식으로 복구하여 외부 iframe 플레이어를 찾을 수 있습니다. 영상 도우미는 확장 프로그램 아이콘으로 켠 현재 탭에서만 동작하며, 새 탭 또는 다른 웹사이트로 이동하면 자동으로 켜지지 않습니다.
- 영상 플레이어 내부에 별도 '영상 도우미' 실행 버튼을 추가하지 않습니다.

## 브랜치

이 코드는 `feature/resume-playback` 브랜치의 시험 기능입니다. `main`의 v6.0.3을 교체하지 않았습니다. 기능 점검 시 `Code → Download ZIP` 전에 브랜치를 선택하세요.

## 주의

- Chrome의 소리 있는 자동재생 정책을 우회할 수는 없습니다. 차단되면 음소거 자동재생을 시도하며, 필요한 경우 플레이어에서 소리를 켭니다.
- 외부 iframe의 HTML5 비디오를 제어하기 위한 모든 사이트 접근 권한이 필요합니다.
- 플레이어 구조가 다르거나 HTML5 video가 아니라면 자동재생/배속/건너뛰기 중 일부 기능을 지원하지 않을 수 있습니다.
- 실제 운영 사이트에서 동영상의 마지막까지 전 구간 자동 검증한 것은 아니므로 설치 후 실제 회차 이동 및 자동재생을 확인하세요.
